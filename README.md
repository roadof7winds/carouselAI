# carouselAI

Генератор каруселей для Instagram: текст идеи → слайды по шаблону (шрифт, цвет,
размер, подложка) → PNG-картинки → правка на лету → экспорт по одной или zip.
Каждый слайд карусели может иметь свою собственную подложку — не обязательно
одну на всю карусель.

## Архитектура

```
Веб-редактор  ──┐
Telegram-бот  ──┼──> core.CarouselService ──> renderer / template_store / storage
MCP-сервер    ──┘
```

Три интерфейса — тонкие клиенты над одним и тем же ядром `core.CarouselService`;
у них общее хранилище (`data/`), так что карусель, созданную в вебе, можно
доредактировать через бота или наоборот.

- **core/** — вся бизнес-логика, не зависящая от интерфейса:
  - `models.py` — `Template` (лейаут: канвас, текстовый блок, шрифт, подложка по
    умолчанию), `Slide` (текст + свои переопределения шрифта/подложки),
    `Carousel`.
  - `text_splitter.py` — режет сырой текст на слайды по лимиту символов из шаблона.
  - `renderer.py` — рисует один слайд (Pillow): подложка слайда (если задана) или
    подложка шаблона + перенос текста по словам с учётом шрифта/цвета/размера/
    выравнивания.
  - `template_store.py` / `storage.py` — сохранение шаблонов и каруселей на диск
    (JSON + PNG), подложки слайдов хранятся отдельно от подложки шаблона, сборка
    zip-архива.
  - `carousel_service.py` — склеивает всё выше в операции: создать карусель,
    поправить слайд, задать подложку шаблона или конкретного слайда, сохранить
    макет как шаблон, экспортировать.
- **web/** — FastAPI-бэкенд + фронтенд без сборки (чистые HTML/CSS/JS) поверх
  `CarouselService`: форма генерации из текста, карточка на каждый слайд с
  live-правкой текста/шрифта/цвета/размера, загрузка подложки на каждый слайд
  отдельно, сохранение макета как шаблона, скачивание по одной картинке или zip.
  Работает независимо от Telegram.
- **mcp_server/** — MCP-сервер (`MCPServer`) поверх `CarouselService`: инструменты
  `list_templates`, `get_template`, `create_carousel`, `edit_slide`,
  `export_carousel`, `set_template_background`, `set_slide_background`,
  `save_as_template`. Через него с сервисом может работать LLM-агент,
  принимающий решения по обработке текста.
- **bot/** — Telegram-бот (aiogram 3), тонкий клиент поверх `CarouselService`:
  текст → карусель, `/edit` → правка слайда, `/setbg` → подложка шаблона по
  умолчанию, `/setslidebg` → подложка одного слайда, `/export` → zip,
  `/templates` → список.

Данные (сгенерированные карусели, шаблоны, загруженные подложки) хранятся в
`data/` — каталог создаётся автоматически и не коммитится.

## Запуск

```bash
pip install -e ".[dev]"
pytest                                    # тесты ядра, MCP-инструментов и веб-API

python -m carouselai.web.app              # веб-редактор: http://127.0.0.1:8000
python -m carouselai.mcp_server.server    # MCP-сервер (stdio)

cp .env.example .env                      # и вписать TELEGRAM_BOT_TOKEN, если нужен бот
python -m carouselai.bot.main
```

Веб-редактор не требует Telegram и токена — можно поднимать и пользоваться сразу.

## Подложки

- **Подложка шаблона** — фон по умолчанию для всех слайдов, использующих этот
  шаблон, пока у конкретного слайда нет своей.
  Бот: `/setbg <id_шаблона>` (id можно опустить — `default`), затем фото, либо
  фото сразу с такой подписью.
  Веб: `POST /api/templates/{id}/background` (multipart).
- **Подложка слайда** — своя картинка для одного конкретного слайда одной
  конкретной карусели, не трогает остальные слайды и не меняет шаблон.
  Бот: `/setslidebg <id_карусели> <номер_слайда>`, затем фото, либо фото с такой
  подписью.
  Веб: в карточке каждого слайда есть отдельная загрузка файла — подложка
  применяется только к этой карточке.
  MCP: `set_slide_background(carousel_id, slide_index, image_path)`.

Повторная загрузка заменяет предыдущую подложку, даже если у неё было другое
расширение файла.

## Что дальше (не реализовано)

- Персистентное состояние "последняя карусель" на пользователя в боте (сейчас —
  в памяти процесса, для одного инстанса; веб-редактор этой проблемы не имеет —
  id карусели всегда в URL/ответе API).
- Библиотека шаблонов с превью-картинками (сейчас — список по id/имени).
- Создание нового шаблона "с нуля" через форму в веб-интерфейсе (API
  `POST /api/templates` уже есть, в UI кнопки пока нет — новый шаблон
  сейчас создаётся через "сохранить макет карусели как шаблон").
- Автоподбор контраста текста под подложку, водяной знак/брендкит поверх
  текущего `watermark_text`, экспорт под разные форматы (Reels-обложка, Stories).
