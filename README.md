# carouselAI

Генератор каруселей для Instagram: текст идеи → слайды по шаблону (шрифт, цвет,
размер, подложка) → PNG-картинки → правка на лету → экспорт по одной или zip.

## Архитектура

```
Telegram-бот  ──┐
                 ├──> core.CarouselService ──> renderer / template_store / storage
MCP-сервер    ──┘
```

- **core/** — вся бизнес-логика, не зависящая ни от Telegram, ни от MCP:
  - `models.py` — `Template` (лейаут: канвас, текстовый блок, шрифт, подложка),
    `Slide`, `Carousel`.
  - `text_splitter.py` — режет сырой текст на слайды по лимиту символов из шаблона.
  - `renderer.py` — рисует один слайд (Pillow): подложка + перенос текста по словам
    внутри текстового блока с учётом шрифта/цвета/размера/выравнивания.
  - `template_store.py` / `storage.py` — сохранение шаблонов и каруселей на диск
    (JSON + PNG), сборка zip-архива.
  - `carousel_service.py` — склеивает всё выше в операции: создать карусель,
    поправить слайд, сохранить макет как шаблон, экспортировать.
- **mcp_server/** — MCP-сервер (`MCPServer`) поверх `CarouselService`: инструменты
  `list_templates`, `get_template`, `create_carousel`, `edit_slide`,
  `export_carousel`, `set_template_background`, `save_as_template`. Через него с
  сервисом может работать LLM-агент, принимающий решения по обработке текста.
- **bot/** — Telegram-бот (aiogram 3), тонкий клиент поверх `CarouselService`:
  текст → карусель, `/edit` → правка слайда, `/setbg` → подложка шаблона,
  `/export` → zip, `/templates` → список.

Данные (сгенерированные карусели, шаблоны, загруженные подложки) хранятся в
`data/` — каталог создаётся автоматически и не коммитится.

## Запуск

```bash
pip install -e ".[dev]"
cp .env.example .env   # и вписать TELEGRAM_BOT_TOKEN

pytest                       # тесты ядра
python -m carouselai.bot.main         # Telegram-бот
python -m carouselai.mcp_server.server  # MCP-сервер (stdio)
```

## Загрузка подложки

`/setbg <id_шаблона>` (id можно опустить — тогда берётся `default`), затем прислать
фото — бот скачает его, сохранит в шаблон и пришлёт превью с примером текста поверх
новой подложки. Тот же результат за один шаг: прислать фото сразу с подписью
`/setbg <id_шаблона>`. Повторная загрузка заменяет прежнюю подложку, даже если
раньше был файл другого формата.

## Что дальше (не реализовано в этом скелете)

- Библиотека шаблонов с превью в боте, а не только списком id.
- Персистентное состояние "последняя карусель" на пользователя (сейчас — в памяти
  процесса бота, для одного инстанса).
- Автоподбор контраста текста под подложку, водяной знак/брендкит поверх текущего
  `watermark_text`, экспорт под разные форматы (Reels-обложка, Stories).
